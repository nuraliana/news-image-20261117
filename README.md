# The World in One Day — 17 November 2026

Entry for the make.fun bounty [news-image-20261117](https://make.fun/bounty/news-image-20261117):
one 1024×1024 newspaper-front-page image summing up Tuesday, 17 November
2026 in six verified stories — Ukraine striking the Kerch Bridge again as
Russia hits Kyiv's bridges, tankers hit by mines near the Strait of Hormuz
and drones fired at a U.S. base in Bahrain, the first Xi–Trump–Putin
three-way meeting confirmed for Shenzhen, the Pentagon failing its audit
for a ninth year, Japan scrambling jets over a Russian airspace incursion,
and four allies urging Israel to open Gaza's crossings for aid.

The image is drawn with Python + PIL (DejaVu fonts, geometric illustration
panels, no photos, no network, no randomness). `main.py` copies the
finished `entry.png` to the output directory.

## Run locally

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `out/entry.png` (1024×1024 PNG).
